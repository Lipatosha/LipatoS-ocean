# LipatoS — Ocean RU

Русскоязычная версия интерфейса **Ocean 2.0.3** для Foundry VTT 14.

## Готово в v1.0.0

- Переведены все **619 из 619** строк официального словаря `OCEAN`.
- Дополнительно переведены **494** подписи и сообщения, которые в исходном коде были жёстко записаны на английском или китайском: конструктор кораблей, паруса, снасти, материалы, редакторы, диагностика и уведомления.
- Сохранены идентификаторы, настройки мира, исходные изображения и 3D-ресурсы. Русификация не изменяет пользовательские данные.
- Для динамических окон перевод применяется при их открытии; новые элементы обрабатываются автоматически.

## Установка

[Установить в Foundry из manifest](https://github.com/Lipatosha/LipatoS-ocean/releases/latest/download/module.json)

Требуется уже установленный **Ocean 2.0.3** и **Scenic3D 1.0.3+**. Установите этот модуль рядом с ними, активируйте его и выберите русский язык интерфейса Foundry.

**Текущий релиз — русскоязычное дополнение к Ocean**, а не самостоятельная копия его 3D-движка. Это сделано, чтобы выпустить рабочую локализацию через Git без неподключённых бинарных ресурсов. Для самостоятельной сборки предстоит перенести исходные assets/lib/scripts в репозиторий. Она не помечается как готовая до проверки.

## Релизы

Новая версия создаётся GitHub Actions из ветки `main`. Ссылки `manifest` и `download` ведут на последний релиз. В чате архивы не передаются.

Оригинальный автор Ocean: Reslin. Адаптация и русский перевод: LipatoS.
