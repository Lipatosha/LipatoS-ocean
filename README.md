# LipatoS — Ocean

Русскоязычный модуль воды и морских путешествий для Foundry VTT 14.

Репозиторий новой редакции Ocean под управлением LipatoS. Исходная база — Ocean 2.0.3; перенос выполняется напрямую в Git. Пока идёт перенос движка и ресурсов, здесь **нет готового релиза для установки**.

## Что сохраняем

- Процедурная вода в регионах: океан, реки, озёра и мелководье.
- Волны, пена, отражения, блики, следы токенов и кораблей.
- Морские путешествия, 3D-корабли и настройка их внешнего вида.
- Настройки качества изображения и производительности.
- Совместимость с Foundry VTT 14 и интеграция с Scenic3D.

## Принципы

Интерфейс на русском; исходные ресурсы используются без обработки, кроме явно согласованной оптимизации. Изменения и релизы ведутся через GitHub, без обмена архивами в чате. Сторонние лицензии и атрибуция сохраняются.
