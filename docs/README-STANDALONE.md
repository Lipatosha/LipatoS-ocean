# LipatoS — Ocean

Самостоятельный русскоязычный модуль живой воды и морских 3D-путешествий для Foundry VTT 14.

**Ocean и Scenic3D устанавливать отдельно не требуется.** Движок кораблей, библиотека Three.js, модели, текстуры и перевод входят в этот пакет. Исходный код Ocean и Scenic3D объединён в одном релизе по переданным владельцу проекта правам. Сохранены авторские атрибуции исходных и сторонних ресурсов.

## Возможности

- Области воды: озёра, реки, океан, волны, пена, прозрачность, течения.
- Освещение, отражения, интерактивная рябь и кильватер.
- Объёмные 3D-корабли на обычных сценах Foundry.
- Полноэкранные морские путешествия с настройками моря, неба и корабля.
- Полный русский перевод интерфейса Ocean и встроенного Scenic3D.

## Установка

Манифест: https://github.com/Lipatosha/LipatoS-ocean/releases/latest/download/module.json

У модуля сохранён идентификатор `ocean` для совместимости с настройками и областями существующих миров. Если был установлен оригинальный Ocean, замените его через новый манифест. Прежнее дополнение `lipatos-ocean` (Ocean RU 1.0.x) отключите: перевод уже включён в самостоятельный модуль. Отдельный Scenic3D также следует отключить, чтобы не запускать один и тот же 3D-движок дважды.

Исходные модели сохраняют обязательную атрибуцию; см. `THIRD_PARTY_LICENSES.md`, `vendor/scenic3d/THIRD_PARTY_LICENSES.md` и `assets/model/*/license.txt`.

## Разработка

Исходные файлы поштучно хранятся в `upstream/ocean/` и `upstream/scenic3d/`. `tools/build-standalone.py` строит единый рабочий пакет в `dist/ocean/` без загрузки зависимостей из интернета. Релиз собирает GitHub Actions. Архивы исходников в Git не хранятся.
